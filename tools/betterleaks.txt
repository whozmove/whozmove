# `release` the one a release carries (tools/release.sh): the same finished version, so what you try is what ships, and

# release's own checksums.txt and checksums.txt.sigstore.json:

#     --certificate-identity https://github.com/betterleaks/betterleaks/.github/workflows/release.yml@refs/tags/v<version> \
#     --certificate-oidc-issuer https://token.actions.githubusercontent.com
